# MicroPKI Demo Script

Демонстрационный скрипт `demo/demo.py` проводит зрителя через **полный жизненный цикл PKI**: от инициализации Root CA до отзыва скомпрометированного сертификата.

## Запуск

```bash
python demo/demo.py
```
## Требования
* Установленный пакет micropki (pip install -e .)
* Свободные порты 8090 (репозиторий) и 8091 (OCSP)
* Опционально: colorama для цветного вывода в Windows
## Шаги демонстрации
### 1-2. Инициализация PKI
* Создаётся самоподписанный Root CA (RSA-4096, 10 лет) и Intermediate CA (RSA-4096, 5 лет), подписанный корнем.

### 3-6. Выпуск различных типов сертификатов
* Server (TLS) с DNS SAN
* Client с email SAN
* Code-signing для подписи файлов
* OCSP responder с EKU=OCSPSigning
### 7. Генерация CRL
* Создаётся первичный Certificate Revocation List промежуточного CA.

### 8-9. Запуск служб
* Запускаются HTTP-репозиторий и OCSP-ответчик в фоне.

### 10. CSR через API
#### Клиент:

* Генерирует пару ключей и CSR
* Отправляет CSR на эндпоинт POST /request-cert с X-API-Key
* Получает подписанный сертификат
### 11-12. Проверка валидного сертификата
* Полная проверка цепочки (chain + revocation через CRL)
* Прямой OCSP запрос — статус GOOD
### 13-15. Code Signing
* Подпись файла приватным ключом code-signing сертификата
* Успешная проверка подписи
* Обнаружение модификации файла (подпись становится невалидной)
### 16-17. Применение политик
#### Демонстрируются автоматические отказы:

* Wildcard SAN (*.example.com) → блокируется
* Срок действия 999 дней → блокируется (max 365)
### 18-19. Отзыв сертификата
#### Сертификат, выпущенный через API, отзывается с причиной keyCompromise. Перегенерируется CRL.

### 20-21. Обнаружение отзыва
* OCSP теперь возвращает REVOKED
* Полная валидация цепочки завершается ошибкой с указанием причины
### 22. Симуляция компрометации
#### Команда ca compromise для клиентского сертификата:

* Отзывает сертификат
* Заносит публичный ключ в compromised_keys
* Генерирует экстренный CRL
### 23-25. Аудит и Certificate Transparency
* Проверка целостности журнала аудита (SHA-256 хеш-цепочка)
* Просмотр всех событий уровня AUDIT
* Проверка наличия сертификата в CT log
### Ожидаемый результат
#### В конце все 25 шагов должны быть отмечены [OK]. Если демо завершилось успешно — PKI работает корректно во всех ключевых сценариях.

### Очистка
#### Скрипт автоматически останавливает фоновые сервисы при завершении (через try/finally). Артефакты остаются во временной директории и удаляются ОС при следующей перезагрузке либо вручную:
```powershell
Remove-Item -Recurse -Force $env:TEMP\micropki_demo_*
```
